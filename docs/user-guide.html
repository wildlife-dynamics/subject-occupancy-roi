User Guide

How to load the workflow, choose the subject group and regions, and read the results.

1. Load the workflow

In the workflow runner, add a new template using this repository's URL, then select subject-occupancy-roi from the templates list.

2. Data sources

  • An EarthRanger data source, set up as a connection. It provides both the subjects' GPS fixes and the regions.

3. Settings

Only the workflow name, time range, data source and subject group must be filled in. Choosing the regions is strongly recommended.

Regions

The EarthRanger features to measure occupancy in. They are also drawn on the map.

Select regions byFieldDescription
Feature sets (default)Feature set namesEvery feature in each named set becomes a region, e.g. Boundaries. Leave empty to use every feature set on the site.
Feature typesFeature type namesEvery feature of these types becomes a region, e.g. Conservancy or Park, whichever set it is in.
Feature IDsFeature IDsIndividual features, by their EarthRanger ID.

Click Add under the chosen option for each name or ID. Names must match EarthRanger exactly, including capitals; a wrong name stops the run with a list of the names that exist.

Leaving Feature sets empty fetches every feature on the site, which can include large sets such as roads. Name the sets or types you need to keep runs quick.

Subject Group Name

FieldDescriptionDefault
Subject Group Name (required)The subject group whose home ranges are measured, picked from a drop-down of the data source's subject groups. ⚠️ A group with mixed subtypes could lead to unexpected results.—

4. Run it and read the results

Click Submit. When the run finishes, the dashboard shows:

  • Home Range Map: each subject's home range, coloured from the core (50%) to the outer edge (99.9%), over the regions.
  • Occupancy: one row per subject and region its home range reaches.
ColumnMeaning
Subject NameThe subject
regionThe region's name, from the feature's name (or a numbered "Region n" if it has none)
Region Area (km²)The whole region's area
Area Covered (km²)The part of the region inside the subject's 99.9% home range
Occupancy (%)Area Covered ÷ Region Area × 100

Regions the home range doesn't reach, and lines and points such as roads, aren't listed. The table is also saved as CSV in the results folder (ECOSCOPE_WORKFLOWS_RESULTS).
